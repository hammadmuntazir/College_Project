# GitHub Dashboard Clone — Frontend Practice

A college project that recreates a GitHub-style dashboard layout using HTML and CSS.

## Live preview

[Open the deployed project](https://college-project-zeta-weld.vercel.app/)

## Tech stack

- HTML
- CSS
- Static image assets

## Run locally

Download or clone the repository and open `index.html` in a browser.

## Scope and limitations

This is a frontend layout exercise. It is not connected to the GitHub API and should not be described as a functional dashboard unless API integration is added.

## Portfolio context

This project is secondary to my Data Engineering portfolio and is retained to show earlier frontend experience.
